Detailed Description

Run the EGS5 event generator to produce a StdHep file.

Required parameters are seed, target_thickness, beam_energy, num_electrons
Optional parameters are: bunches, bound_electrons, bound_target_z, bound_ekin_min, bound_debug

The bound_* parameters configure Moller scattering off bound target electrons in EGS5 programs that support it (moller_v5). They are written to bound.dat in the run directory:

  • bound_electrons: 1 to sample the struck electron from the shell-wise Compton profiles (impulse approximation), 0 for free electrons at rest as in moller_v4
  • bound_target_z: atomic number used to pick data/shellwise_Compton_profile/zNNN.dat (default 74)
  • bound_ekin_min: minimum kinetic energy of the Moller secondary in MeV for the correction (default 1.0)
  • bound_debug: number of corrected interactions written to bound_debug.txt (default 0)
